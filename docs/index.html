费用怎么算的

token 统计是真实的，费用是估算的。口径如下，想精确对账就看官方后台。

  • 1
    按模型参考价分别计价

    缓存命中、未命中、输出、推理各按各的单价，与官方计费规则一致。

  • 2
    内置 DeepSeek 官方空闲时段价

    高峰时段为 2 倍，因此估算费用是下限值，实际以官方账单为准。

  • 3
    价格可覆盖，模型名前缀匹配

    插件配置里的 prices 表按模型设置单价，deepseek-v4-flash-0731 这类带版本后缀的模型名会自动命中。

  • 4
    官方余额双通道对照

    配置 DEEPSEEK_API_KEY 后调用官方余额接口，与本地估算并排展示；未配置时自动隐藏，不影响其他功能。

Install

三条命令装好

推荐从 GitHub 安装并锁定版本标签，升级时打新标签即可。

dsh-token-stats · install
$ dsh plugin --profile web add "github:FantasyStarry/dsh-token-stats#v0.10.0"
# 在 $DSH_HOME/profiles/web/cordis.patch.yml 中激活：
- insert: # 该行下方添加
    - id: token-stats
      name: dsh-token-stats
# 重启 dsh web 生效，刷新浏览器页面加载客户端插件
  1. 1
    添加插件，锁定版本标签 #v0.10.0
  2. 2
    激活：在 web profile 的 cordis.patch.yml 里 insert 一行
  3. 3
    重启 dsh web，刷新浏览器；可选在插件配置里加 prices 单价表

数据口径说明

与日志一致

每次成功模型调用计一次，失败与重试不计；插件每次加载会把今天的统计从会话日志整体重建，不漏计也不重复。

费用是估算

按内置参考价或你配置的价格估算，DeepSeek 官方价格随时可能调整，对账以平台账单为准。

密钥安全

API Key 只在服务端使用，浏览器只访问本机路由，不会下发任何密钥。
